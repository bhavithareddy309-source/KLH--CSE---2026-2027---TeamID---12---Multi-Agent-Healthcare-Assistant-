 1 . Abstract:-
-> The Multi-Agent Healthcare Assistant is an intelligent healthcare support system designed using a multi-agent architecture. The project aims to provide users with accessible, efficient, and organized healthcare assistance through multiple specialized AI agents.

-> Each agent is responsible for a specific healthcare-related task, such as understanding user queries, providing general health information, analyzing symptoms, offering health recommendations, and assisting with healthcare-related information retrieval.

-> The agents work together to process user requests and provide relevant responses. The system aims to improve accessibility to healthcare information and simplify the process of obtaining basic healthcare guidance. It is designed as a support tool and does not replace professional medical consultation, diagnosis, or treatment.

2. Project Objectives:-
  > Develop a healthcare assistant using a multi-agent architecture.
  > Divide healthcare-related tasks among specialized agents.
  > Enable communication and coordination between agents.
  > Provide relevant healthcare information to users.
  > Improve the efficiency of healthcare information retrieval.
  > Create a user-friendly healthcare assistance system
